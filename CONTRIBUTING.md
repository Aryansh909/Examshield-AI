# Contributing to ExamShield AI

Thank you for your interest! This is a portfolio/research project. Contributions that improve accuracy, performance, or documentation are welcome.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Make your changes
4. Run tests: `make test`
5. Open a Pull Request with a clear description

## Code Style

- Follow PEP 8. Max line length: 120 characters.
- Run `make lint` before submitting a PR.
- All public functions and classes must have docstrings.

## What to Contribute

**Welcome:**
- Bug fixes
- Detection accuracy improvements
- Documentation improvements
- Performance optimisations
- New violation detection signals (with evidence)

**Out of Scope:**
- Changing the tech stack (Flask → FastAPI, OpenCV → other, etc.)
- Adding a cloud backend / authentication system
- Docker / Kubernetes configuration

## Reporting Issues

Please include:
- OS and Python version
- Full error traceback
- Webcam model if relevant
- Steps to reproduce
